#Tech-Workshop_Registration-Form-2026

#Project Introduction

This project is Tech Workshop Registration Form. I built this project to practice HTML forms and grow my skills as a beginner web developer. Finishing a real page, reviewing the code, and understanding every part is more useful to me than only following a tutorial .The form collects participant details and lets someone register for the workshop. I checked the structure myself so I know how the labels, input fields, and submit button work together. I used HTML to build the page and form. I also used AI as a coding assistant for the first draft, then reviewed and corrected the code until I understood it well. This project is one step toward becoming a web developer by building complete pages I can explain on my own.
